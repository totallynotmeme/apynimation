# apynimation

This project is the result of me messing around for a few hours and building something i personally find cool.
Currently there aren't many features, but it helps me simplify a lot of repetitive code i would've written otherwise

You can see the example in `examples/demo_scene.py` file. I will write a documentation later...
in case you'd ever want to use this over [Manim](https://github.com/3b1b/manim) or other graphics libraries, for some reason

>[!NOTE]
>If the symlink in `examples/` doesn't automatically work (*ModuleNotFoundError: No module named 'apynimation'*),
>you can delete it and simply move the entire `apynimation/` folder into `examples/apynimation/`.
>If you're planning to use this in your project, create a copy of `apynimation/` and drop it in your project folder.
